وضعیت قصه عوض نمی‌شود و برای قصه‌گو دوباره به بررسی نمی‌رود؛ فقط محتوای صفحهٔ قصه به‌روز می‌شود. صدای قصه از این‌جا قابل تغییر نیست.

دستهٔ قصه
حداقل یک دسته باید انتخاب شود.
در صفحهٔ قصه دیده نمی‌شود؛ فقط در تگ meta description و اشتراک‌گذاری شبکه‌های اجتماعی استفاده می‌شود. حدود ۱۵۰ تا ۱۶۰ کاراکتر بهتر است. اگر خالی بگذارید، از توضیح قصه استفاده می‌شود.
اگر فایلی انتخاب نکنید، تصویر فعلی می‌ماند. حداکثر ۳ مگابایت.
